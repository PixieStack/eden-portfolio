## 🛠️ Tech Stack

### Frontend

- **React 18** — UI library
- **TypeScript** — Type safety
- **Vite** — Fast build tool
- **Tailwind CSS** — Styling
- **React Router** — Client-side routing
- **Lucide React** — Icons

### Design

- **Fonts**: Syne (headings), Space Grotesk (body)
- **Colors**: Orange (#F97316), Purple (#C084FC), Dark (#0A0A0F)
- **Effects**: Glass morphism, animations, gradients

## 🚀 Deploy to GitHub Pages (FREE)

This project deploys directly from the `docs` folder - **no GitHub Actions needed!**

### Setup Steps:

1. Push code to GitHub
2. Go to repo **Settings** → **Pages**
3. Source: **Deploy from a branch**
4. Branch: **main** | Folder: **/docs**
5. Click **Save**
6. Wait 2 minutes - your site is live!
